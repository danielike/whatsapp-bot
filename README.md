# WhatsApp Bot

Simple bot that allows you to run commands and do automatic audio translation in whatsapp using Groq AI Free tier.

## Previous requirements

- https://docs.docker.com/engine/install/
- https://github.com/FlareSolverr/FlareSolverr
- https://github.com/evolution-foundation/evolution-api
- https://dotnet.microsoft.com/en-us/download/dotnet/10.0

## Available commands

- `/random number @Username` => gets some random content from a configure site (it should have a /random option by itself).
- `/buzz time_in_seconds @Username` => each n seconds, it sends a message to the given username.
- `/stop` => stop all buzz commands previously done.
