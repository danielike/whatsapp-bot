# WhatsApp Bot

Simple bot that allows you to run commands and do automatic audio translation in whatsapp using Groq AI Free tier.

## How to Generate Groq API Token

1. **Sign Up / Log In**: Visit [console.groq.com](https://console.groq.com) and create an account or log in. 
2. **Navigate to API Keys**: Go to the **API Keys** section in the left sidebar (or directly to [console.groq.com/keys](https://console.groq.com/keys)). 
3. **Create Key**: Click the **Create API Key** button. 
4. **Name Key**: Enter a descriptive name for your key (e.g., "WhatsApp Bot"). 
5. **Copy Key**: **Copy the generated key immediately**.  Groq shows the key only once; if you lose it, you must generate a new one.
6. **Store Securely**: Save the key in a secure location or environment variable (e.g., `GROQ_API_KEY`).
